# 04 — 跨端体验与平台差异

## 原则

- **同一账号、同一后端、同一功能集**；布局随屏幕适配，不维护两套业务逻辑。  
- 手机：单手、竖屏、底部导航。  
- 桌面：宽屏、侧栏、键盘快捷键、可多栏（如历史+记忆并排）。  

## 平台差异表

| 能力 | Android / iOS | Windows / macOS |
|------|---------------|-----------------|
| 配网引导 | 可考虑跳转系统 Wi‑Fi / 复制密码 | 以说明书式步骤为主 |
| 推送通知 | FCM / APNs（后置） | 系统通知或仅应用内红点 |
| 安全存储 Token | Keychain / Keystore | OS 凭证库 |
| 窗口 | 全屏页栈 | 最小宽度建议 ≥ 1000px；支持分栏 |
| 关闭行为 | 回桌面 | 可选最小化到托盘 |
| 分发 | PWA：URL 即达，可安装到主屏 | PWA：浏览器安装为桌面应用 |

## 响应式断点（建议）

| 宽度 | 布局 |
|------|------|
| < 600 | 手机：Bottom Navigation |
| 600～1024 | 平板：Navigation Rail |
| > 1024 | 桌面：侧栏 + 主内容 + 可选详情栏 |

## 无障碍与国际化

- 首版中文即可；文案键值化便于后加英文。  
- 关键按钮不低于触控最小尺寸（手机）。  

## 性能

- 列表分页，与后端 `limit` 对齐  
- 图片/表情资源少；勿在客户端缓存全量历史无上限
