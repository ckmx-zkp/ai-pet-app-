# 01 — 项目概述与用户场景

## 一句话

让用户在**手机或电脑**上管理自己的 AI Pet：定好人设、看见记忆与历史、看日运小记——语音陪伴仍发生在玩具本体上。

## 目标用户

| 阶段 | 用户 | App 要解决什么 |
|------|------|----------------|
| Next | 内测好友/同事 | 不用打开管理台也能设星座/MBTI、翻记忆 |
| Later | 小规模体验用户 | 日运/小记、多设备、导出数据、桌面常驻查看 |

开发者本人可继续用 `ai-pet-admin`；App 面向「主人」体验。

## 关键场景（JTBD）→ App 交付

| 场景 | 用户要完成的事 | App 交付 | 不在 App |
|------|----------------|----------|----------|
| S0 定人设 | 选星座+MBTI | 人设页、问卷 | KB 编译（后端） |
| S1 陪伴对话 | 和宠物说话 | 展示「设备在线/最近会话」状态 | 实时麦克风通话（在硬件） |
| S2 表情互动 | 看它眨眼 | 外设状态只读；可选「请求表情」若后端提供指令 API | 直接 MCP |
| S3 回顾沉淀 | 昨天聊了啥、记得什么 | 历史时间线、记忆列表编辑 | — |
| S4 日运/小记 | 看今日一句 | 日运卡片、摘要列表 | 重历算 |
| S5 研发运营 | 改 KB/模型 | **不做**（去 admin） | — |
| S6 养成（后） | 日记/成长 | V1.x Feed | — |

## 价值主张（对用户话术）

1. 给宠物选好星座和性格，它聊起来就不像通用助手。  
2. 对话和记忆在你账号下可查可删。  
3. 手机和电脑都能管——随时看看它记得什么。  

## 成功标准（客户端）

- 内测用户 5 分钟内完成：注册 → 绑设备 → 定人设  
- 记忆页可完成新增/删除  
- 同一账号手机与桌面数据一致（后端为真源）
