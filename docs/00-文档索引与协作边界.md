# 00 — 文档索引与协作边界

## 五仓关系

```text
D:\Home_Work\
├── ESP32_XIAOZHI\     固件 + 产品母文档
├── xiaozhi-server\    实时语音 / OTA / 设备 MCP
├── ai-pet-backend\    业务 API / KB / 记忆真源
├── ai-pet-admin\      Web 管理台（开发/运营）
└── ai-pet-app\        本仓：手机 + 桌面用户端
```

## 本仓可以做

- 用户注册登录、绑设备、人设（星座×MBTI）、历史、记忆、日运/小记只读、外设状态只读  
- 配网引导（Wi‑Fi 说明 / 深链；具体配网协议跟固件能力）  
- 数据导出入口、账号与隐私设置  
- 桌面端窗口化布局与托盘（可选）  

## 本仓不要做

| 禁止 | 原因 |
|------|------|
| 知识库 draft/publish | 运营能力，在 admin |
| 直连设备 UDP/MQTT 传语音 | 语音在硬件↔xiaozhi-server |
| 在客户端编译星座 KB | 真源与 Compiler 在 backend |
| 浏览器 Agent / 研发 Harness UI | 非 C 端 |
| 首版社交、排行榜、NFC 卡牌 | 产品 Declined |

## 依赖

| 依赖 | 用途 |
|------|------|
| `ai-pet-backend` 用户 API | 全部业务数据 |
| 固件配网能力 | 绑设备前上网 |
| （可选）推送服务 | 日运/摘要就绪通知，后置 |
