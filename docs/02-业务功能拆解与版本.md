## 业务拆解（按域）

### 1. 账号域
- 注册、登录、退出、改密（后）  
- Token 安全存储（Keychain / Credential Manager）  

### 2. 设备域
- 绑定 device_uid、重命名、解绑  
- 在线状态、固件版本展示（后端镜像）  
- 配网：图文步骤 + 常见失败（连不上热点/密码错）  

### 3. 人设域（产品核心）
- 太阳星座选择（12）  
- MBTI 选择或短问卷  
- 展示当前元素提示（如「双鱼继承水相」一句话教育）  
- follow_latest / 钉版本  
- 保存后文案：下次对设备说话时生效  

### 4. 资产域
- 历史：按日分组、删除确认  
- 记忆：列表、标签、来源、审核候选  
- 分析：卡片流（摘要/小记）  

### 5. 表达域（只读为主）
- 当前眼睛 emotion / 更新时间  
- （后）若后端提供「远程请求眨眼」API，再加按钮——默认不进 V0.2  

### 6. 设置与合规
- 导出数据、删除账号（后）、隐私说明  
- 服务器地址（内测可配置 API Base，方便指向自建环境）  

## 明确不做（与产品 Declined 一致）

真宠巡航、大 IP 卡牌、Agent 智商卖点、在 App 里算星盘。
